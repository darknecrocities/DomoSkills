CLI Package Manager Quickstart

Install skills directly into any project with zero configuration. Supports Google Antigravity, Claude Code, Cursor, Codex, and OpenCode.

1. Initialize DomoSkills in your repo
npx domoskills init
2. Add verified skills for your AI coding agent
npx domoskills add react-performance owasp-agent-guardian
3. Audit installed skills for security & compliance
npx domoskills audit
